Project methodology

From dataset to insights

High-level workflow used for the project.

1. Data preparation

The supplied EV dataset was loaded into Tableau. Fields were reviewed and assigned appropriate dimensions and measures for analysis.

2. Visualization

Visualizations were created to explore sales trends, manufacturers, categories, battery types, price versus range, and customer ratings.

3. Dashboard and story

Related charts were assembled into a dashboard and organized into a Tableau Story for guided exploration.

4. Web integration

Flask serves this page and embeds the publicly published Tableau Story so viewers can explore the analysis from a web application.
