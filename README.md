# Electric Vehicle Market Performance & Insights

A data analytics project exploring electric vehicle market performance using Tableau Public and Flask.

## Project Overview

This project presents EV market insights through an interactive Tableau Story embedded in a Flask web application.

## Technologies Used

- **Tableau Public:** Data visualization, dashboard, and story.
- **Python:** Application programming language.
- **Flask:** Web framework.
- **HTML and CSS:** Website structure and styling.

## Features

- Interactive Tableau Story embedded in the website.
- EV market dashboard and visualizations.
- Project overview and methodology.
- Responsive website layout.
- Direct access to the published Tableau Story.

## Run Locally

1. Install Python 3.10 or newer.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Install dependencies:

   ```bash
   py -m pip install -r requirements.txt
   ```

5. Start the Flask application:

   ```bash
   py app.py
   ```

6. Open `http://127.0.0.1:5000` in your browser.

An internet connection is required to load the embedded Tableau visualization.

## Project Workflow

1. Load and prepare the supplied EV dataset in Tableau.
2. Create visualizations and assemble the dashboard.
3. Organize the analysis into a Tableau Story.
4. Publish the Story to Tableau Public.
5. Embed the published Story in the Flask web application.

## Note

Flask serves the website and embeds the published Tableau Story. The analytical visualizations are handled in Tableau.
